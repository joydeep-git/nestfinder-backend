# 🏡 Nest Finder - Backend

This is the backend API for **Nest Finder**, a property listing and buying platform. It is built with **Node.js**, **Express.js**, **MongoDB**, and **TypeScript**.

---

## 🚀 Features

✅ **Authentication & Authorization**  
- User registration (Signup)  
- User login with JWT authentication  
- Secure cookie-based authentication
- Cookie timeout status check on every page load
- Logout functionality
- Middleware for protected routes  

✅ **User Management**  
- Fetch user details  
- Update user profile  
- Delete user account  

✅ **Property Listings**  
- Add new properties  
- Fetch all properties  
- Fetch a single property by ID  
- Update property details  
- Delete a property  

✅ **Search & Filters**  
- Search properties by location  
- Filter by price, size, and amenities  


✅ **Secure API & Middlewares**  
- JWT-based authentication middleware  
- Global error handling middleware  
- Input validation for all API endpoints  

---

## 🛠️ Technologies Used

- **Backend**: Node.js, Express.js, TypeScript  
- **Database**: MongoDB (Mongoose ODM)  
- **Authentication**: JWT, Cookies 
- **Deployment**: Render
